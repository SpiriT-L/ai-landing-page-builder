# AI CV Analyzer Landing

Premium dark SaaS landing page for an AI-powered resume analysis service for IT professionals.

## Stack
- Next.js 16
- React 19
- TypeScript
- CSS

## Commands
- npm install
- npm run dev
- npm run build

## Sections
Hero, Features, How it works, Pricing, FAQ and CTA.

The Analyze my CV CTA is currently a demo action and should be connected to the production CV upload/analyze flow.
